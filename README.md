# Clipboard Landing Page – Frontend Mentor Challenge

This project is a responsive, accessible multi-section webpage built for the fictitious company **Front end mentor Co.**  
It showcases semantic HTML, Tailwind, and accessibility best practices.

## Source

- [Challenge Link](https://www.frontendmentor.io/challenges/clipboard-landing-page-5cc9bccd6c4c91111378ecb9)

## Overview

This project is a responsive landing page built based on the Clipboard Landing Page challenge from Frontend Mentor. The challenge was to build out this landing page and get it looking as close to the design as possible. The goal of the challenge is to accurately translate a provided design into a functional, pixel-accurate webpage while following best practices in HTML, CSS (Tailwind), and responsive design. In order users should be able to View the optimal layout for the site depending on their device's screen size

## Technologies Used

- HTML5
- TailwindCSS
  - Flexbox
  - Grid
  - CSS Variables
- ARIA for accessibility support

## Approach & Implementation

### Semantic HTML

The page was built using **semantic HTML5 elements** to improve accessibility, SEO, and maintainability.  
Key elements used include:

- `<header>` for the hero section
- `<main>` to wrap the primary content
- `<section>` to group related content
- `<article>` for feature blocks
- `<figure>` and `<figcaption>` for images
- `<footer>` and `<nav>` for navigation and links

This structure avoids unnecessary `<div>` elements and creates a clear document hierarchy.

---

### Styling & Layout

- TailwindCSS Flexbox and Grid were used for layout and alignment.
- A mobile-first approach was applied to ensure responsiveness.
- Consistent spacing, typography, and color usage were maintained to match the design.
- Reusable utility colors and fonts.

### Customizations

In addition to the base challenge requirements, the following enhancements were implemented:

- A smooth **fade effect at the bottom of background images** using modern CSS (`mask-image` with a linear gradient).
- Improved accessibility with meaningful heading structure and `aria-label` attributes.
- Cleaner visual hierarchy by refining spacing between sections.

---

## Challenges & Solutions

### Challenge 1: Achieving a Pixel-Accurate Layout

**Problem:**  
Matching the spacing, font sizes, and alignment exactly to the design. because I did not have access to the Figma file.

**Solution:**  
Careful inspection of the design picture and incremental adjustments to margins, padding, and layout structure were made to closely match the intended appearance.
